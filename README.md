# Portal Lawatan Sambil Belajar 2026

Portal pendaftaran Lawatan Sambil Belajar ke MARDI Tanjung Karang & Bukit Melawati.

## GitHub Pages
Upload semua fail/folder dalam pakej ini ke root repository:
- index.html
- .nojekyll
- README.md
- assets/

Kemudian aktifkan GitHub Pages melalui Settings > Pages > Deploy from a branch > main > /(root).

Backend kekal menggunakan Google Apps Script dan Google Sheets. Jangan upload fail Apps Script atau data murid/penjaga ke repository public.
